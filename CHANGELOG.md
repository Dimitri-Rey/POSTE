# Changelog

## 1.47.0 — first public release · première version publique

**English**

Poste, a self-hosted workspace: mail, calendar, tasks, files, an AI assistant and server status, on desktop and phone.

- Mail: all IMAP mailboxes in one list, live arrival (IMAP IDLE), reading without marking as read, isolated HTML, phishing and spam warnings with reasons, important mail, sender blocking, AI reply drafts, mail → task or appointment, and "Le point", a daily AI summary also sent every morning. Never any sending.
- Calendar: list, week and month views, quick add in French, reminders; read-only Google, Outlook, iCloud, Nextcloud, Fastmail and iCal feeds.
- Tasks: priorities, due dates, gestures on the phone.
- Files: full-text search, previews and image viewer, selection and zip, note editor with AI help, tidying with AI, document redaction, PDF conversion; Word, Excel, PowerPoint (Collabora) and diagrams (draw.io) as options.
- Assistant: chat interface for Hermes Agent, with human approval, attachments, deliverables with preview and model switching.
- Server: CPU, memory, GPU, disks, systemd services, alerts.
- Embedded sites: your other web apps in Poste's menu.
- Backups: local folder, NAS, SMB, WebDAV, SFTP, S3 and clouds through rclone; encryption, full and incremental backups, rotation, file recovery.
- Everywhere: global search, mobile interface installable on the home screen, Android app, ntfy notifications, live dictation.
- Installation with Docker Compose, or Python with a systemd service.

**Français**

Poste, poste de travail auto-hébergé : mails, agenda, tâches, fichiers, assistant IA et état du serveur, sur ordinateur et téléphone.

- Mails : toutes les boîtes IMAP dans une liste, arrivée en direct (IMAP IDLE), lecture sans marquer comme lu, HTML isolé, alertes d'hameçonnage et de spam expliquées, mails importants, blocage d'expéditeurs, brouillons de réponse par l'IA, mail → tâche ou rendez-vous, et « Le point », résumé du jour par l'IA, envoyé aussi chaque matin. Jamais aucun envoi.
- Agenda : liste, semaine, mois, ajout rapide en français, rappels ; Google, Outlook, iCloud, Nextcloud, Fastmail et flux iCal en lecture seule.
- Tâches : priorités, échéances, gestes au doigt.
- Fichiers : recherche dans le contenu, aperçus et visionneuse, sélection et zip, éditeur de notes aidé par l'IA, rangement par l'IA, masquage des documents, conversion en PDF ; Word, Excel, PowerPoint (Collabora) et diagrammes (draw.io) en option.
- Assistant : interface de discussion pour Hermes Agent, avec accord humain, pièces jointes, livrables avec aperçu et choix du modèle.
- Serveur : processeur, mémoire, carte graphique, disques, services systemd, alertes.
- Sites intégrés : tes autres applications web dans le menu de Poste.
- Sauvegardes : dossier local, NAS, SMB, WebDAV, SFTP, S3 et clouds par rclone ; chiffrement, complètes et incrémentielles, rotation, récupération de fichiers.
- Partout : recherche globale, interface mobile installable, application Android, notifications ntfy, dictée en direct.
- Installation par Docker Compose, ou en Python avec un service systemd.
