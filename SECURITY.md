# Security policy · Politique de sécurité

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private reporting instead: **Security** tab → **Report a vulnerability**. Include the version of Poste, what an attacker can do, and the steps to reproduce.

You will get an answer as soon as possible. A fix is prepared before any public disclosure.

## Signaler une faille

Merci de **ne pas ouvrir de ticket public** pour un problème de sécurité. Passe par le signalement privé de GitHub : onglet **Security** → **Report a vulnerability**. Indique la version de Poste, ce qu'un attaquant peut faire et les étapes pour le reproduire.

Tu recevras une réponse dès que possible. Un correctif est préparé avant toute publication.

## Scope · Périmètre

Poste is designed for **one user, on a private network** (VPN, Tailscale, or a reverse proxy with extra authentication). Exposing it directly to the Internet is not a supported setup.

Poste est conçu pour **un seul utilisateur, sur un réseau privé** (VPN, Tailscale, ou proxy inverse avec une authentification en plus). L'exposer directement sur Internet n'est pas une installation prise en charge.
